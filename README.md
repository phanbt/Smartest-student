# Who Wants to Be the Smartest Student?

A quiz-show game for students in Singapore aged 8 to 12.

- 10 questions per game from English, Mathematics, Science, Physics, Chemistry, Geography, History and Literature, getting harder as you go
- One cookie for every correct answer
- Two helpers per game: 50:50 and Ask the Teacher
- An explanation after every answer and a full review at the end

The whole game is a single file, `index.html`. Open it in a browser, or play it online with GitHub Pages.

## Languages

- English: `index.html`
- Vietnamese (Ai Là Học Sinh Thông Minh Nhất?): `vi/index.html`

Each start screen links to the other language.
